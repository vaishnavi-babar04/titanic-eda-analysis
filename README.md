# Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on exploring the Titanic dataset using Python. It analyzes passenger information to identify patterns and factors that influenced survival.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
1. Loaded and explored the Titanic dataset.
2. Checked missing values and statistical summaries.
3. Cleaned missing data in the Age and Embarked columns.
4. Removed the Cabin column due to a large number of missing values.
5. Created visualizations to understand passenger data.
6. Analyzed survival patterns based on gender and passenger class.

## Key Findings
- Female passengers had higher survival rates than male passengers.
- First-class passengers had better survival rates.
- Most passengers were between 20 and 40 years old.
- Gender and passenger class were important factors associated with survival.

## Files
- `titanic_eda.py` – Python code for data analysis.
- `Titanic-Dataset.csv` – Dataset used in the project.

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

Run the Python file:

```bash
python titanic_eda.py
```
